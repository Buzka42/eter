# Eter

Eter is a private-first Flutter health companion organized around one Aether
surface and a Settings Sanctum. The current build combines local health data,
a free-form Journal, non-causal pattern discovery, optional Firebase AI
composition, and symbolic Arcana/Vessel presentation.

## Current release

- Version: `0.2.0+5000`
- Android APK: `artifacts/Eter-0.2.0+5000-release.apk`
- Play bundle: `artifacts/Eter-0.2.0+5000-release.aab`
- Verification: 109 Flutter tests pass; `flutter analyze lib test` is clean.
